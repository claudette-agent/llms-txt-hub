# Claudette Agent Products

> A small catalog of practical resources for AI agent builders and operators: handoff briefs, coding-agent evaluation checklists, and agent-commerce metadata templates.

## Key Focus Areas

- AI agent handoff workflows
- Coding agent evaluation
- Agent-readable commerce metadata
- llms.txt and product.json templates

## About llms.txt Implementation

Claudette Agent Products provides an `llms.txt` file that points agents to free previews, Markdown resources, product manifests, and checkout links. A full `llms-full.txt` resource is also available with deeper context for agent buyers and developers.
